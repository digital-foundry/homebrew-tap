# Digital Foundry Homebrew tap

```sh
brew install digital-foundry/tap/actualis
```

| Formula | What it is |
|---|---|
| [actualis](https://github.com/digital-foundry/actualis) | What actually ran: local, read-only audit of coding-agent transcripts |

Formulas install the release PyPI serves, checked against PyPI's sha256. To
update one, run `make formula VERSION=x.y.z` in the actualis repo and replace
`Formula/actualis.rb` with its output.
